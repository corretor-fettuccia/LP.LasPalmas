PUBLICAÇÃO
Envie todo o conteúdo desta pasta para a raiz do seu serviço de hospedagem, GitHub Pages, Netlify, Vercel ou servidor web. A página é estática e não exige banco de dados.

SEO E INDEXAÇÃO
O pacote inclui robots.txt, llms.txt, llms-full.txt, ai-catalog.json, content/export-validation.json e sitemap.xml com imagens quando habilitado. O sitemap usa a URL canônica configurada no editor, imagens incorporadas/publicadas de plugins e é referenciado pelo robots.txt. Confira VALIDACAO-EXPORTACAO.txt e o relatório JSON para os avisos de qualidade. Ícones e imagens sociais carregados em PNG/WebP ficam na raiz como icon.png ou icon.webp e share.png ou share.webp. Para visualização correta em redes sociais, configure a URL canônica pública HTTPS.

SEGURANÇA
O HTML inclui uma CSP compatível com <meta>. O arquivo _headers e security/headers.conf também trazem a política de cabeçalho com frame-ancestors para hospedagens que suportam configuração de headers.

FORMULÁRIOS E CONTATO
Os formulários e CTAs usam as integrações configuradas no editor. O Form.v4 mantém o endpoint, a validação e as notificações do componente original.
